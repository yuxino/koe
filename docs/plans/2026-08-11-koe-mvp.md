# Koe MVP Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build a runnable Chrome MV3 extension that captures current-tab audio, sends short WAV chunks to a local subtitle service, and renders timestamped captions over the page.

**Architecture:** The extension uses `chrome.tabCapture` for user-initiated tab audio capture, an MV3 offscreen document for Web Audio and PCM encoding, a service worker for message routing, and a content script with a Shadow DOM overlay. The local Node service defaults to mock mode and exposes a Ding-frame-compatible Fun-ASR adapter behind environment variables.

**Tech Stack:** Chrome Manifest V3, vanilla JavaScript, Web Audio API, AudioWorklet, Node.js built-in `http`, Node test runner.

### Task 3: Add extension capture and routing

**Files:**
- Create: `manifest.json`
- Create: `background.js`
- Create: `offscreen.html`, `offscreen.js`, `audio-worklet.js`

**Behavior:** A user click requests a tab stream ID. The offscreen document keeps playback audible, captures mono PCM, encodes 16 kHz WAV chunks, posts them to the local service, and forwards returned subtitle lines to the active tab.

**Verification:** The extension loads from `chrome://extensions` without manifest errors and Start/Stop messages reach the local service.
