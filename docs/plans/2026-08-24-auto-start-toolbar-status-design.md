# 自动启动与工具栏状态设计

## 目标

Koe 在本地精准模式下不再要求用户先点开扩展弹窗。主视频真正开始播放后，扩展自动建立本地字幕会话，并在浏览器工具栏图标上持续显示当前状态。

## 行为约定

- 页面只加载或视频暂停时不启动，主视频进入播放状态后才自动启动。
- 自动启动只作用于当前触发播放的页面；Koe 仍保持全局单会话，不允许多个标签页同时分析。
- 用户点击停止后，当前视频会话保持停止，后续 `PAGE_READY`、播放和媒体换源事件都不能把它偷偷重启。
- 用户打开新的页面或新的标签页播放视频时，可以建立新的自动会话。
- 用户仍可通过弹窗或侧边栏明确重新启动已停止的页面。

## 工具栏状态

工具栏使用全局徽标，因为 Koe 一次只运行一个字幕会话，状态不应随着当前激活标签页消失：

- `··`：正在定位媒体、准备模型或生成首批字幕。
- `ON`：字幕已经可用。
- `!`：启动或运行失败，需要用户查看详情或重试。
- 空白：没有正在运行的会话，或用户已主动停止。

徽标同时更新扩展图标的悬停标题，提供完整中文状态；颜色只承担明确的状态语义。

## 实现边界

- 自动启动沿用现有 `PAGE_READY` / `VIDEO_CHANGED` 和主视频发现逻辑，不新增网站白名单。
- 本地模式允许手动对暂停视频启动，但自动路径必须要求 `playing === true`。
- `userStopped` 仍是自动重启的硬边界，明确启动才清除该标记。
- 工具栏状态由后台会话状态统一派生，避免在每个异步分支分别维护造成漂移。

## 验证

- 自动测试覆盖播放自动启动、暂停不启动、手动停止不重启，以及准备、运行、错误、空闲四种徽标。
- 完整运行现有 JavaScript 与 Helper 回归。
- 在 ego-lite 中加载扩展，实际确认无需打开弹窗即可启动，并检查工具栏徽标变化。
